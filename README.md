# Q Agency redesign: Direction B · Blueprint / Systems

A static prototype of the full q.agency site (348 pages), rendered through this design direction. All text, SEO,
images and links are verbatim from the live site; only the visual layer is new.

**Vercel:** import this repo with Framework Preset **Other**; leave the build command and output directory empty.
`vercel.json` sets trailing-slash URLs, library caching and the one legacy redirect.

Notes: images are hotlinked from media.q.agency; forms are inert (prototype alert); the Accessibly widget may only
activate on Q's registered domain.
